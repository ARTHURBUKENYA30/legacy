Owner quick guide — click to open

You do not need to edit website code. Use the tabs above for everyday updates.

  1. Add or update a person, programme, event or photo: open its tab, fill in the form, select a photo if needed, then click Save record.
  2. Show it on the live website: tick Published before saving. Leave it unticked if you are still preparing the item.
  3. Change an existing item: find it in the list and click Edit. Make changes and click Update record.
  4. Upload photos: choose a JPG, PNG, WebP or GIF image under 8 MB. Wait for the save message before leaving the page.
  5. Homepage text: this section is for advanced settings. The text box uses JSON formatting; avoid changing it unless you know the structure. Ask your website support person if unsure.
  6. When finished: open the public website in another tab and refresh it to confirm the change. Click Sign out when done.

If something fails, copy the error message or take a screenshot and send it to your website support person. Never share your password.
